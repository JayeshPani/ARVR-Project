## Unit interpretation (2026-09-21)

The source NRRD omits `space units`. Conversion now requires explicit
`--source-units mm` and writes NIfTI spatial units as mm. The case-specific
interpretation follows [Slicer's coordinate documentation](https://www.slicer.org/wiki/Slicer3%3ACoordinates)
and [the Slicer developer explanation](https://discourse.slicer.org/t/ras-coordinate-system-world-coordinate-system/29024/2).
This is a documented source-convention interpretation, not a unit field
present in this NRRD. Other sources with missing units must be checked separately.
The original array axis codes are LPS; the NIfTI affine maps them into RAS
world coordinates. No voxel-axis canonicalisation or resampling is performed.
