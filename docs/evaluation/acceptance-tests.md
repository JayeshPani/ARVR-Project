## Brain integration and interaction review — 2026-09-21

### Existing integration checked

- The imported source GLB is converted from metres/Y-up to source RAS mm.
  Raw bounds match the source conversion within 0.00001 mm. The browser GLB
  loader preserves the simplified model bounds and axes.
- Original brain: 679,926 triangles. Browser brain: 15,000 triangles.
  Baseline tumour: 10,106 triangles. Combined baseline: 25,106 triangles.
- The case manifest references the actual brain asset and includes its
  automated/unreviewed limitations. Simplification reduces visible detail;
  no quantitative fidelity or clinical accuracy claim is made.

### Implemented and checked

- Shared controls for opacity/visibility, tumour isolation/focus, six camera
  views, zoom/fit, auto-rotation, three clipping directions and reverse cut.
- Brain-only clipping by default; explicit option to clip tumour too.
- Surface selection with the current tumour mask volume; source/overlay
  MRI toggle; state persists across Explore/Scenarios and geometry changes.
- Empty resection updates the region label to zero and disables tumour
  focus; resetting the scenario restores the region and its controls.
- Three Node tests pass: right-handed RAS/display mapping and anatomical
  camera sides, both cut endpoints in all six directions, and opposite
  half-spaces under the display transform.
- TypeScript/Vite production build passes. Existing chunk size warning
  remains (main JS approximately 542 kB uncompressed).
- Desktop Chromium interaction checks pass; 390px responsive layout has
  no horizontal overflow. This is not physical iPhone/Safari validation.
- GPU inspection confirms brain geometry receives disposal and allocated
  geometry count reaches zero when the viewer is disposed. This repairs
  the prior context-mesh leak; a ten-minute endurance test remains pending.

The browser model is a visual context surface, including fragmented/open
parts. Shader cutaways leave open edges and do not produce segmented MRI
cross-sections. Target-device performance, AR, clinical surface validation,
and an independent asymmetric fixture through browser rendering remain pending.

Browser follow-up: all 35 states also pass with the shared controls. Click
selection reports the current tumour mask volume; a delayed old request does
not overwrite a newer frame; an injected brain-asset 404 leaves tumour
inspection usable. No uncaught page errors were observed; the injected 404
produced the expected network-console error.
