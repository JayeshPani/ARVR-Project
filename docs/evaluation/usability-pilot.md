# Small usability pilot

Plan section 4. Exploratory usability evidence only — not proof of clinical
benefit or a statistically established educational advantage. If
participants are unavailable, replace this with a structured developer
walkthrough rather than inventing results.

## Tasks (each participant performs all five)

1. Find and isolate the tumour.
2. Reveal it through surrounding anatomy.
3. Locate the corresponding MRI slice.
4. Compare baseline and one scenario.
5. Identify whether the displayed state is observed or simulated.

Counterbalance 3D/AR viewing order across participants where practical.
